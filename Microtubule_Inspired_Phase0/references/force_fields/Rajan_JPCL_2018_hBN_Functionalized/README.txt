-----------------------------------------------------------------hBN Desalination------------------------------------------
The zip file contains LAMMPS input files for NaCl desalination using the P36-B(H) case, located in the "hBN-Desalination" folder, which includes in.lmp, data.lmp, and pair.lmp files. The force field information for intermolecular and intramolecular interactions is provided in the hBN_functionalized-FFTOOLS.ff file.

The folder "Optimized_hBN_structure" contains the DFT-optimized nanoporous functionalized hBN sheet.

MD simulations were run using LAMMPS version 29 Sep 2021.

The folder "CP2K-Inputfiles-Charge-calculation" contains CP2K input and output files for charge calculation using the Default DDAP case. CP2K version 7.1 was used for these calculations.
